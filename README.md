**Real-time NHL stats dashboard with AI-powered game predictions.**

My brother Andrew plays professional hockey in Germany's DEL league. Every hockey season our family gathers around screens — I got tired of slow, ad-infested sports apps, so I built our own.

**The stack is pure Elixir muscle:**
- **Phoenix LiveView** — zero-JS real-time UI over WebSockets
- **GenServer army** — supervised processes polling NHL & DEL APIs every 30s
- **ETS caching** — sub-microsecond reads, 1000x faster than Redis
- **Claude AI predictions** — game outcomes modeled on matchups & form
- **Fly.io** — globally distributed on a single **$5/month** machine
